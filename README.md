## Лабораторная 3:
## Исследование 1:
Получившиеся байты:
Для числа 305419896: 78-56-34-12
Для числа 1: 01-00-00-00
Для числа 256: 00-01-00-00
Для числа 65536: 00-00-01-00
## Ответы:
1. Компьютер всегда отводит 4 байта, даже если число маленькое. Остальные места забиваются нулями.
2. Единица перескакивает в следующий байт.
3. Потому что число стало еще больше, и ему уже нужно три байта вместо двух. Единица перескакивает еще дальше.

## Исследование 2:
Значение BitConverter.IsLittleEndian: True
Получившиеся байты числа: 78-56-34-12
Компьютер использует порядок Little-endian (от младшего к старшему)

## Исследование 3:
Потому что в кодировке UTF-8 русские буквы занимают по 2 байта. А английские занимают по 1 байту.
Количество байт "ABC": 3
Количество байт "Привет": 12

## Исследование 4:
Английская "A": 41 (1 байт)
Русская "А": D0-90 (2 байта)

## Исследование 5:
Потому что компьютер не хранит информацию о том, в какой кодировке были записаны байты.

## Контрольные вопросы:
1. Что такое байт и сколько бит содержит один байт?
2. Почему int занимает несколько байтов?
3. Что показывает BitConverter.GetBytes()?
4. Что означает BitConverter.IsLittleEndian?
5. Почему порядок байтов может отличаться от привычной записи числа?
6. Почему количество символов строки не всегда равно количеству байтов?
7. Что делает Encoding.UTF8.GetBytes()?
8. Зачем для обратного преобразования текста используется
Encoding.UTF8.GetString()?
9. Почему одни и те же байты могут интерпретироваться по-разному?
10.Чем представление числа в памяти отличается от представления текста?
## Ответы: 
1. Байт - это единица измерения информации. 1 байт содержит 8 бит.
2. Чтобы можно было записать большие числа.
3. Показывает как число хранится в памяти компьютера.
4. Порядок хранения байтов.
5. Потому что число записывается от младшего байта к старшему.
6. Потому что английские буквы занимают по 1 байту, а русские буквы занимают по 2 байта.
7. Превращает текст в последовательность байтов.
8. Для того, чтобы собрать байты обратно в текст.
9. Потому что байты это просто числа. Смысл им придает программа.
10. Число хранится фиксированного размера, например, 4 байта. А текст - это набор отдельных байтов, где каждая буква занимает разное место.

Нет, просто интерпретировать байты нельзя. Нужно точно знать кодировку, по которым они записаны.
